# IOTSC 原交付模板展示器

以学长交接的 `index.html`、`style.css`、`main.js` 为主体，保留原舞台标题、副标题、字体边距、模型取景、光照、阴影、模糊反射、右下视角控件及页脚。

- 独立完整页面：`/assets/product-viewer/index.html`
- 控制台中央舞台：`/assets/product-viewer/index.html?dashboard=1`
- `?embed=1` 作为 dashboard 模式的兼容别名。

相对原交付的必要差异：

1. 本地资源使用相对地址，构建后由控制台的同源静态服务提供，当前实时入口端口为 3001。
2. dashboard 模式隐藏独立页头与侧栏，模型下方提供一键展开、恢复组装、布局、视角、零件；旋转、复位、全屏竖排放在右下缩放键上方。控件复用完整页的 DOM 与状态；“零件”打开底部搜索列表，独占布局空间并触发模型重新取景，不覆盖舞台。再次点击零件、关闭按钮或 Escape 收起并恢复焦点。
3. 独立页默认完整组装（展开程度 0%、间距 50%，布局为球形爆炸），保留侧栏、三种布局、拆装、搜索、滑块、视角、截图和手动手势控制，切换布局保留单件拆装状态。嵌入页默认空地协同结构；从此模式点一键展开会切到按结构展开，点击单件则切到按结构布局仅移开选中的部件。嵌入页切换布局沿用当前展开程度并重算可移动部件。
4. 独立页使用原交付深色舞台与侧栏、珊瑚红强调色，嵌入页沿用控制台青绿配色。按结构展开时，原始轮组位移会低于初始地面；阴影与反射平面随动画中的最低部件一起下降，恢复组装后回到原地面，避免轮胎被地面遮挡，不修改模型或拆解轨迹。
5. 加载错误时提供重试按钮。

“全屏”在顶层打开无嵌入参数的完整模型页面，页面提供返回主界面入口。独立页联合包围盒取景的 1.28 留白、原曝光/灯光/阴影参数保持不变；嵌入页使用更紧凑取景、2 倍像素采样及更明亮的曝光/环境补光，以提升控制台内零件边缘和暗部的可读性。模型文件未经修改，含 270 个零件，约 124 MB。

安装本目录依赖后运行 `npm run build` / `npm test`，也可复用交接项目依赖：

```powershell
node build.mjs "交接项目/node_modules"
node test.mjs "交接项目/node_modules"
```

构建输出 `../assets/product-viewer/`。后台需支持 `.glb`、`.mjs`、`.wasm`、`.task` 静态文件。模型界面不连接真实设备，不自动申请摄像头权限。
