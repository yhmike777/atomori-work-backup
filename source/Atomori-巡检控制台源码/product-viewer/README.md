# IOTSC 原交付模板展示器

以学长交接的 `index.html`、`style.css`、`main.js` 为主体，保留原舞台标题、副标题、字体边距、模型取景、光照、阴影、模糊反射、右下视角控件及页脚。

- 独立完整页面：`/assets/product-viewer/index.html`
- 控制台中央舞台：`/assets/product-viewer/index.html?dashboard=1`
- `?embed=1` 作为 dashboard 模式的兼容别名。

相对原交付的必要差异：

1. 本地资源使用相对地址，构建后由控制台的同源静态服务提供，当前实时入口端口为 3003。
2. dashboard 模式隐藏独立页头与侧栏，模型下方提供一键展开、恢复组装、布局、视角、零件；旋转、复位、全屏竖排放在右下缩放键上方。控件复用完整页的 DOM 与状态；“零件”打开底部搜索列表，独占布局空间并触发模型重新取景，不覆盖舞台。再次点击零件、关闭按钮或 Escape 收起并恢复焦点。
3. 独立页默认完整组装（展开程度 0%、间距 50%，布局为球形爆炸），保留侧栏、三种布局、拆装、搜索、滑块、视角、截图和手动手势控制，切换布局保留单件拆装状态。嵌入页默认空地协同结构；从此模式点一键展开会切到按结构展开，点击单件则切到按结构布局仅移开选中的部件。嵌入页切换布局沿用当前展开程度并重算可移动部件。
4. 独立页使用原交付深色舞台与侧栏、珊瑚红强调色，嵌入页沿用控制台青绿配色。按结构展开时，原始轮组位移会低于初始地面；阴影与反射平面随动画中的最低部件一起下降，恢复组装后回到原地面，避免轮胎被地面遮挡，不修改模型或拆解轨迹。
5. 加载错误时提供重试按钮。

“全屏”在顶层打开无嵌入参数的完整模型页面，页面提供返回主界面入口。独立页联合包围盒取景的 1.28 留白、原曝光/灯光/阴影参数保持不变；嵌入页使用更紧凑取景、2 倍像素采样及更明亮的曝光/环境补光，以提升控制台内零件边缘和暗部的可读性。模型文件未经修改，含 270 个零件，约 124 MB。

安装本目录依赖后运行 `npm run build` / `npm test`，也可复用交接项目依赖：

```powershell
node build.mjs "交接项目/node_modules"
node test.mjs "交接项目/node_modules"
```

构建输出 `../assets/product-viewer/`。后台需支持 `.glb`、`.mjs`、`.wasm`、`.task` 静态文件。模型界面不连接真实设备，不自动申请摄像头权限。

## 摄像头手势接入（2026-10-28）

已核对用户提供的 `gesture_control_20261018/gesture_control`：它同时提供网页与原生 Blender 两种入口。当前完整模型页面使用网页模式，Three.js、MediaPipe JS/WASM 与识别模型均已在本地，无需安装或启动 Blender；原生模式所需的 Blender 运行时也已经包含在交付包内。保留当前 270 零件 Atomori 整机模型，不用交付包的 91 零件演示模型替换。

- 从控制台模型的“全屏”进入完整页面，侧栏顶部可直接启用摄像头；页头“摄像头手势”可定位该面板。
- 先握拳，再张掌展开；张掌后握拳还原。首次静态姿势仅建立起点。单手完整入镜，展开/还原不再要求手指朝上；移动旋转仍要求朝上，双掌缩放仍要求双手朝上、掌心面向镜头。鼠标操作优先。
- 用户要求提高触发灵敏度（2026-10-28）：单手分类置信度 65%→45%，确认时间 350→120 ms、至少 2 帧；检测/存在/跟踪最低置信度 55%→35%。保留姿势转换、有效关键点、单帧抖动过滤和失联后清空起点，持续张掌不会反复展开。确认时间取决于实际推理帧率，不保证任意遮挡或光照下都能识别。
- 本次验证：模型/转换/掌运动/双手/摄像头生命周期回归通过；控制器实测桩验证横放手掌在 45% 下展开和还原、不误旋转或重复触发。构建后的页面使用真实 MediaPipe 与公开照片合成视频完成首次张掌不展开、拳→掌展开、掌→拳还原，4 项识别资源同源、无页面错误（视频时间约 17.2 s）；这不替代用户现场光照下的真人验证。
- 随后现场验证：用户物理摄像头中握拳约 76%–96%、张掌约 51%–65%，多次观察到展开滑块 0→50→0；用户确认“现在都可以了”。未录制摄像头视频，验收截图只保留模型和界面说明。
- 点击关闭、收起手势面板或离开页面释放摄像头。等待权限、视频启动或模型加载时离开，也不会在异步完成后重新打开摄像头。页面离开时释放识别器。
- 摄像头画面仅在浏览器内识别，不录制、不上传。浏览器首次启用需要摄像头权限；权限拒绝、设备占用或拔出会显示具体原因。

交付包与当前识别模型 SHA-256 均为 `97952348cf6a6a4915c2ea1496b4b37ebabc50cbbf80571435643c455f2b0482`。现有项目的稳定帧容错及单手状态机已比交付包更新，予以保留，避免还原旧版阈值。

验证：`npm test` 覆盖 270 零件布局、单手转换、双手缩放、方向限制和 6 组摄像头生命周期场景。另用独立 Edge 无头实例与交付包的公开照片合成视频，经过真实 MediaPipe 识别器，验证首次张掌不展开、握拳到张掌展开、张掌到握拳恢复；4 个识别资源全部同源加载，无页面错误。该验证未使用用户物理摄像头，真人光照、遮挡与镜头视角仍取决于现场条件。
