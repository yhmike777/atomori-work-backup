# 车端部署文件

这是本次会话已部署修改的本机存档，不是完整的 CAR_ws 工程。
目录结构对应树莓派绝对路径：车端完整页面（含位置保留摇杆、已删除无人机云台模块）、RTSP 采集脚本和相机 systemd 单元。
最初打包时树莓派处于关机状态；2026-10-28 已按用户要求通过 H100 恢复连接，当前入口与实测状态见仓库根 README。本目录仍是原部署文件存档，不表示下载后已部署。
重新部署前应核对车端文件是否被其他人更新，备份后再替换；仅相机脚本/服务更新需要重启 car-front-camera.service。
车端完整部署工程仍以原 CAR_ws 工程为基础。原始视频恢复测试不访问设备。

在仓库根目录运行隔离测试：`python "车端部署文件/tests/test_rtsp_recovery.py"`。测试从本目录的部署存档读取采集代码，不需要 OpenCV 或连接树莓派。
